Proyek terbaru saya: membuat halaman di web yang menampilkan paragraph.

di proyek baru saya, saya mencoba membaut sebauh paragraph yang berisi sekumpulan kata yang lumayan panjang untuk ditampilkan menjadi isi proyek saya sekarang.

saya mencoba menambahkan beberapa link perintah HERF ke dalam footer nya dan memberikan link tujuan nya untuk menentukan tempat tujuan dari tombol tersebut ketika dipencet.

dan saya juga menambahkan gambar supaya terlihat seperti contoh yang diberikan, walaupun nya juga tidak tau apakah harus atau tidak.

saya juga sebenarnya mau menambahkan beberapa hisana tapi saya kurang tau kalau hanya menggunakan html, setau saya harus dipisah supaya lebih rapi dan bagus.

saya juga beberapa kali tidak bisa menampilkan gambar nya karena saya masih kurang mengerti, jadi saya tanya ai untuk membantu masalah nya.

saya menggunakan teks ini hanya untuk mengisi mungkin, tapi karena perintah nya meminta begini jadi saya buat begini karena jika tidak teks nya tidak bisa digulir ke bawah atau ke atas.

maaf jika kata nya kurang jelas saya hanya memberikan kata ini untuk mengisi teks nya supaya bisa digulir.
